# DSA in Java – Part 08: Binary Search Tree (BST)

This repository contains my Java implementations and practice programs focused on **Binary Search Trees (BST)**, an important non-linear data structure in Data Structures and Algorithms.

## 📚 Topics Covered

- Introduction to Binary Search Tree
- BST Properties and Structure
- Creating a Binary Search Tree
- Insertion in BST
- Searching in BST
- Deletion in BST
- Inorder Traversal
- Preorder Traversal
- Postorder Traversal
- Minimum and Maximum Value in BST
- Finding the Inorder Successor
- Finding the Inorder Predecessor
- BST Validation
- Practice Problems Based on BST

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Binary Trees, Recursion, Tree Traversals, Binary Search Tree

## 🎯 Learning Objectives

- Understand the structure and properties of BST.
- Implement insertion, searching, and deletion operations.
- Learn different tree traversal techniques.
- Improve recursive problem-solving skills.
- Understand the importance of BST in efficient searching and sorting.
